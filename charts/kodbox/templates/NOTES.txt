On first start kodbox installs itself against the configured database and
redis.
{{- if .Values.admin.bootstrap }}
The admin account is created on that first start (existing installs are not
changed):
  user:     kubectl -n {{ .Release.Namespace }} get secret {{ include "kodbox.adminSecretName" . }} -o jsonpath='{.data.KODBOX_ADMIN_USER}' | base64 -d
  password: kubectl -n {{ .Release.Namespace }} get secret {{ include "kodbox.adminSecretName" . }} -o jsonpath='{.data.KODBOX_ADMIN_PASSWORD}' | base64 -d
{{- else }}
The admin account is NOT set yet: the first person to open the site
creates it, so open it and set the admin password right away.
{{- end }}
